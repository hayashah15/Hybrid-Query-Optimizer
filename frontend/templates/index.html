Hybrid Vector Search adaptive query planner · pgvector

Every query is routed by the planner, not chosen by hand. When a category filter is selective enough to shrink the search space, the planner filters first; otherwise it ranks the full table by vector similarity.

How the planner decides

The planner estimates selectivity — the fraction of rows a category filter would keep — from PostgreSQL's pg_stats planner statistics, before running anything.

Below 10% match → filter first, then rank the small remainder
10% or more (or no filter) → rank everything by similarity first
